# 用户偏好与灰区 — v2026.11.11-fupan-highlight

已定的（用户原话在作者工作区 07-划线回顾 讨论文件）见 Feature Spec；这里只记 forge-dev 识别出的剩余灰区和采用的默认值（用户要求尽快推进，按默认，未逐项再问）。

| 灰区 | 采用 | 理由 |
| --- | --- | --- |
| 服务托管的根 | 工作区根（FUPAN_ROOT 的上两级），只放行 FUPAN_ROOT 和 FUPAN_KB 两棵目录，其余 404；`/` 跳 `/记录/复盘/` | 经验图片按「复盘根 → ../../知识/…」相对路径引用，只托管复盘根会断 |
| 生成用的命令 | 环境变量 `FUPAN_CLAUDE` 指定绝对路径；没设时依次找 PATH 里的 `claude`、最新 VS Code 扩展的 `native-binary/claude`；模型用 CLI 默认，`FUPAN_CLAUDE_MODEL` 可覆盖 | launchd 里没有 shell 别名；作者的 `claude` 是带代理的别名 |
| 语言与依赖 | serve.py、push.py 都用 Python 3.9+ 标准库，不引第三方包 | 和 skill 现有脚本一致，装了就能跑 |
| 划线数据进不进 git | `记录/复盘/_划线/` 跟工作区仓库走（备份），不另加忽略 | 作者私有仓库；学习笔记不属于只留本机的商业打算 |
| LaunchAgent 名 | `com.antonailog.fupan-serve`、`com.antonailog.fupan-push` | 沿用 publish-desk、diary-studio 的命名 |
| 推送配置 | 作者工作区 `工具/复盘改造/2-结果区/划线推送/config.json`（chat_id、时间），凭证从工作区 `.mcp.json` 的 feishu 参数读，不复制 | 凭证只留一处 |
| 页面轮询讲解 | 有 pending 的 ❓ 时每 10 秒查一次，最多 3 分钟 | 「划完就出」，不常驻轮询 |
