### BUG-001 [低] 到点或跳过切换阶段时，主按钮底色有一次 120ms 的颜色过渡

- **现象**：专注到点切到休息（或点跳过、休息到点）那一刻，主按钮底色不是直接从砖红变灰青，而是在约 0.12 秒里经过一串中间色。
- **影响**：每次切阶段一次，肉眼几乎看不出；不影响任何功能。与 DESIGN §5.1「颜色和文字直接切换，无过渡、无闪烁」和 §1.2 原则 3「全页唯一的过渡是按钮悬停变色」不一致。
- **证据**：V14。鼠标移开、等悬停过渡结束后让专注到点，`document.getAnimations()` 里出现 `CSSTransition background-color@primary 120ms`；按真实时间连续采样计算底色：rgb(163,65,45) → rgb(150,70,53) → rgb(129,78,67) → rgb(119,81,73) → rgb(85,94,95) → rgb(68,101,106) → rgb(59,104,112)；点跳过切回专注同样出现中间色。完整采样在 `.gstack/qa-reports/facts.json` 的 `V14`。
- **根因定位**：`style.css:178` `.primary { transition: background-color var(--pomo-btn-ms) ease-out; }` 本是给悬停用的，`style.css:234` `body[data-phase="break"] .primary` 换阶段底色改的是同一个属性，于是阶段切换也走了过渡。
- **本次引入**：是（提交 ad9de43，设计实现阶段）。
- **已知情况**：forge-eng 已在 ENGINEERING §九技术债、需求设计文档 [docs/modules/番茄钟.md](<modules/番茄钟.md>) 待拍板里列出，默认「接受现状」。
- **分类**：设计取舍 → 待用户判断，不自动登记 BF、不阻塞上线。
- **修复建议**：先由 forge-design 拍板——认可这次过渡就改 DESIGN §5.1 的措辞；坚持直接切换就交 forge-design-impl 调样式，让过渡只在悬停 / 按下时生效（不得改「样式与行为的接口」，行为代码不加类名）。改完后回归 V14、V09、V15。

| **把标签页转入后台**：试了最小化窗口、同一窗口开新标签并激活 | 三种办法下页面仍是 `visible`，定时器不被放慢 | 无法在无头浏览器里复现后台标签页，**这项没量到** |
| **模型：每分钟只唤醒一次**：按 Chrome 对长时间隐藏页面的限速方式，让页面的渲染进程只在每个整分钟恢复 1 秒，其余时间挂起（工具自检：挂起期间页面定时器一次都没跑） | 提示音在结束后的第一次唤醒响起，晚 45 秒；只响一次、只计一次、切段正确 | 这是机制模型，不是浏览器真实行为；只能说明「最晚大约晚一分钟、不会重复响或重复计数」 |

结论：页面在前台时几乎准时；页面在后台时预计最多晚一分钟左右（模型推断，未实测）。PRD §五 P1 的「晚得影响使用再讨论」需要需求方按下面的步骤实测后判断。

### 电脑睡眠唤醒（ENGINEERING M2，近似）

把页面的渲染进程挂起（定时器全停、真实时钟照走）60 秒跨过结束时刻再恢复：恢复后 5 毫秒完成到点处理（今天 3 个、休息 05:00），提示音恢复后 3 毫秒响起、只响一次。和真实合盖的差别：浏览器主进程与系统音频设备没有一起睡眠。

> 注：最初用 CDP `Page.setWebLifecycleState` 冻结页面做近似，命令返回成功但定时器照跑，结果作废（留档在 `.gstack/qa-reports/realtime/*-freeze-invalid.*`）；改用挂起渲染进程并加了工具自检。

### 6.3 造状态的方法（页面里没有测试钩子）

| 要造的情形 | 做法 |
|---|---|
| 时间流逝、到点、跨零点、时间回调 | `context.clock.install({ time })` → `goto` → `page.clock.pauseAt(time + 1000)` → `runFor` / `setSystemTime`；时钟跨刷新、跨同一上下文的多个页面共享 |
| 离开期间到点、昨天的记录、损坏记录 | 直接写 `localStorage['pomodoro.v1']`（格式见 ENGINEERING §四.1）后刷新 |
| 浏览器禁止保存 / 写满 | 注入脚本把 `window.localStorage` 换成访问即抛 `SecurityError` 的 getter；或让 `setItem` 在开关打开后抛 `QuotaExceededError` |
| 数提示音、通知权限 | 注入探针包一层 `AudioContext`，统计构造与 `createOscillator`；包一层 `Notification.requestPermission` |
| 声音被拦截 | 让 `AudioContext` 构造抛 `NotAllowedError`；或恢复出进行中且不点任何东西 |
| 回到前台 | 覆盖 `document.visibilityState` 并派发 `visibilitychange`（只验证代码路径，不触发浏览器真实限速） |
| 颜色断言 | CSS 过渡按真实时间走、不受假时钟影响：先把鼠标移开并真实等待 300ms 再取色 |
