# Feature Spec：划线回顾

**版本**: v1.0
**状态**: 已确认（2026-11-11）
**关联 Feature**: fupan-highlight
**讨论与原话**: 作者工作区 `工具/复盘改造/1-工作区/07-划线回顾/2026-11-11-讨论-划线与飞书回顾.md`（第一至九轮）
**页面样稿**: 同目录 `2026-11-11-样稿-划线批注/`（`src/annot/Annotator.tsx`、`read.tsx`、`store.ts`；`preview/打开.html`）

工作台（复盘汇总 / 经验 / 知识）原来只能读。这次加三件事：读的时候划线（⭐ 收藏、❓ 不懂）并写备注；文章读完点「已读」；划过的句子按固定节奏推到飞书群复习。

---

### 一、用户流程总览

**入口**: 浏览器打开 `http://127.0.0.1:4330/`（本地服务托管的工作台），在复盘单篇、旧复盘、经验详情、知识点弹窗里读
**出口**: 飞书群 Learn With AI 里的推送卡片；列表里读过的那一行变灰

```
读到一句 → 选中文字 → 工具条点 ⭐ 或 ❓ → 原文上色、右侧批注栏出卡片（虚线连原句）→ 写备注（可不写）
                │                                   │
                ↓ file:// 打开                       ↓ 服务没响应
              不出工具条                            卡片显示「未保存」，可重试
后台：服务写背景（❓ 再写讲解）→ ❓ 卡片下面出讲解
推送：当晚 21:00「今日新增」→ 第二天 09:00、第三天 09:00「今日复习」→ 满 3 次停推
读完 → 页面最下面点「已读」→ 列表里这一篇整行变灰（再点取消）
```

**流程说明**:
1. 划线：选中正文 ≥2 个字 → 选区上方弹出工具条（⭐、❓ 两个图标）→ 点一个 → 存一条划线，原文上色，右侧出卡片，光标进备注
2. 备注：回车或 Esc 收起；改了就存；卡片上的删除图标删掉这条
3. 生成：服务收到新划线后在后台写「背景」，❓ 另写「讲解」，写完存回这条划线；页面上 ❓ 卡片的备注下面出讲解
4. 推送：每天 21:00 推当天新划的，次日 09:00、第三天 09:00 各推一次复习，每条共 3 次
5. 已读：复盘单篇、旧复盘、经验详情最下面一个「已读」按钮；点了列表里这一篇变灰；再点取消

### 二、系统结构

#### 整体

```
浏览器 ── http://127.0.0.1:4330 ──▶ serve.py（forge-fupan skill，LaunchAgent 常驻）
  │  静态：FUPAN_ROOT 和 FUPAN_KB 两棵目录（index.html、data.js、经验图片……）
  │  接口：/api/health、/api/notes、/api/read
  │                                  │ 读写
  │                                  ▼
  │                       FUPAN_ROOT/_划线/划线.json、已读.json
  │                                  ▲ 读、写推送记录
  │                       push.py（作者工作区，LaunchAgent 每 10 分钟，经接口读写）──▶ 飞书群 Learn With AI
  │                                  │
  └─ 生成：serve.py 收到新划线后调本机 Claude CLI 写背景 / 讲解
```

| 部分 | 放哪 | 职责 |
| --- | --- | --- |
| 阅读页 | skill `tools/fupan-reader/` → `assets/reader.html` | 划线工具条、原文上色、右侧批注栏、已读按钮、列表置灰；去掉知识点旧收藏 |
| 本地服务 | skill `scripts/serve.py` | 托管 FUPAN_ROOT、FUPAN_KB 静态文件（根是工作区根）；划线和已读的增删改查；新划线后台生成背景和讲解 |
| 数据 | `FUPAN_ROOT/_划线/` | `划线.json`（全部划线）、`已读.json`（已读的键列表）；build.py 扫复盘根时跳过 `_` 开头的目录（现状如此） |
| 推送 | 作者工作区 `工具/复盘改造/2-结果区/划线推送/` | 选当次该推的、拼飞书卡片、发群、记推送；飞书凭证和群号只在这里，不进公开仓库 |
| 定时 | 作者工作区，两个 LaunchAgent | 服务常驻（KeepAlive）；推送每 10 分钟醒一次，按北京时间判断（Mac 系统时区是洛杉矶） |

#### 页面键

| 页面 | 键 | 地址 |
| --- | --- | --- |
| 复盘单篇 | `r:<项目>/<模块>/<文件夹>` | `#r=` |
| 旧复盘 | `o:<相对复盘根的路径>` | `#o=` |
| 经验详情 | `s:<经验编号>` | `#s=` |
| 知识点弹窗 | `k:<知识点编号>` | `#k=` |

#### 一条划线存什么

| 字段 | 内容 |
| --- | --- |
| `id` | 唯一编号 |
| `kind` | `star`（收藏）/ `ask`（不懂） |
| `page` | 页面键 |
| `doc` | `{type: 复盘/经验/知识, project, module, title, one}`：项目和模块（经验、知识填领域）、标题、一句话（复盘摘要 why → did；经验的一句话简介；知识点的一句话） |
| `section` | 所在位置，如「二、工作复盘 › 对标分析 › 发送状态与故障恢复」 |
| `block` | 划线所在那一块的原文快照（≤ 2000 字） |
| `quote` | `{exact, prefix, suffix}`（W3C Web Annotation TextQuoteSelector） |
| `note` | 备注，可空 |
| `created_at` | ISO 时间 |
| `gen` | `{status: pending/done/failed, background, explain, at, tries}` |
| `pushes` | `[{n: 1/2/3, at, msg_id}]` |

#### 接口（serve.py）

| 方法 | 路径 | 作用 |
| --- | --- | --- |
| GET | `/api/health` | 页面据此判断能不能划线、能不能点已读 |
| GET | `/api/notes?page=<键>` | 这一页的划线 |
| POST | `/api/notes` | 新建划线（kind、page、doc、section、block、quote、note），返回带 id 的整条；随后后台生成 |
| PATCH | `/api/notes/<id>` | 改备注 |
| DELETE | `/api/notes/<id>` | 删除 |
| GET | `/api/read` | 已读键列表 |
| PUT / DELETE | `/api/read/<键>` | 标已读 / 取消 |
| GET | `/api/notes`（不带 page） | 全部划线，给 push.py 用 |
| POST | `/api/notes/<id>/gen` | 重新生成一次（同步等，最多 120 秒），返回整条；push.py 对 failed 的调用 |
| POST | `/api/notes/<id>/push` | 记一次推送 `{n, at, msg_id}` |

只绑 `127.0.0.1`；写文件用临时文件 + 改名，读写加锁；推送记录经接口写，文件只有 serve.py 一个写入方。
安全：`Host` 只认 `127.0.0.1:<端口>`、`localhost:<端口>`；`Sec-Fetch-Site: cross-site` 一律 403；非 GET 的接口要求请求头 `X-Fupan: 1`；不回任何 CORS 头。
静态托管根是工作区根（FUPAN_ROOT 上两级），只放行 FUPAN_ROOT、FUPAN_KB 两棵目录，其余 404；`/` 跳到复盘根的 `index.html`。

#### 组件（阅读页）

**选区工具条**
- 职责：选中正文后给出两个动作
- 交互：选中 ≥2 个字松开鼠标出现在选区上方居中；点 ⭐ 或 ❓ 存划线；点别处或 Esc 消失；按下工具条不丢选区
- CSS 约束：圆角 8px、边框、弹层底色、阴影；按钮 32×32，图标 18px；⭐ 琥珀实心（fill amber-400 / text amber-500），❓ 紫（violet-500）

**原文上色**
- 用 CSS Custom Highlight API，不改 React 管的 DOM
- 收藏 `rgb(252 211 77 / .42)`，不懂 `rgb(196 181 253 / .45)`；当前那条加深为 `.8` / `rgb(167 139 250 / .6)`；深色主题见样稿

**右侧批注栏（A 样式）**
- 布局：复盘单篇、旧复盘、经验详情的外框加一栏 17rem（与正文间距 3rem），外框最大宽 1720px；知识点弹窗不加批注栏（见下方「知识点弹窗（精简）」）
- 卡片：和原句第一行同高，挤了往下顺延，间距 10px；圆角 8px、边框、卡片底色、内边距 12px / 8px；左边图标，右边备注输入框（15px，一行起随字数长高，宽度变了也重算）；悬停或选中时出删除图标、加 1px 对应颜色描边
- 虚线：从原句末尾在行间空白里走到卡片（`M 原句末尾,行底+2 H 栏左-16 V 卡片顶+19 H 栏左`），`stroke-dasharray 4 3`、线宽 1.25（当前 1.75）、不透明度 .35（当前 1）、颜色同图标
- 联动：悬停卡片或点原文上的划线，这条变成当前（原文加深、线变实、卡片描边）
- ❓ 的讲解：生成好以后显示在这张卡片备注的下面，15px，次要文字色

**知识点弹窗（精简，11-11 用户定「知识点不加备注」「能划，但不要备注栏」）**
- 弹窗保持 880px，不加右侧批注栏、不画虚线、没有备注输入
- 选中文字照样弹 ⭐ / ❓，存划线（note 为空）、原文上色、照常推送
- 点原文上色的地方，在那句话下方出一个小浮层：图标 + 名称（收藏 / 不懂）、❓ 的讲解（生成好了才出）、删除图标；点别处或 Esc 关浮层（Esc 不关弹窗）；保存失败时浮层里显示「未保存」「重试」

**已读按钮**
- 位置：复盘单篇、旧复盘、经验详情正文最下面，上方一条分隔线、上边距 32px，左对齐正文
- 样式：未读时描边按钮「已读」；已读时浅灰底、次要文字色、前面一个勾，悬停提示「再点一次取消已读」
- 列表：复盘汇总「最近」、项目页、经验首页里，已读的那一行整行不透明度 .5，悬停回到 1

**知识点旧收藏（去掉）**
- 删 `kb/favs.ts`、弹窗头的「收藏」按钮、知识页清单的收藏切换和星标；弹窗头只留名字、状态图标、关闭、一句话

### 三、行为场景（Given/When/Then）

#### Requirement R1：划线

页面 SHALL 让用户在复盘单篇、旧复盘、经验详情、知识点弹窗的正文里选中文字后存成 ⭐ 或 ❓ 划线。

##### Scenario: 正常 — 划一句并写备注
- **GIVEN**: 工作台从 `http://127.0.0.1:4330/` 打开，`/api/health` 正常，正在读复盘单篇
- **WHEN**: 选中「把幂等发送、失败分类和恢复验收一起设计」，点 ⭐，输入「三件事绑在一起提」，回车
- **THEN**:
  - UI 状态：这句上色（收藏色），右侧批注栏出一张卡片、虚线连到这句末尾，卡片里是备注
  - 数据变化：`划线.json` 多一条 kind=star、page=r:…、quote.exact=原句、note=备注、gen.status=pending
  - 视觉表现：卡片顶部与原句第一行顶部差 ≤ 4px

##### Scenario: 降级 — 用 file:// 打开
- **GIVEN**: 用户双击 `记录/复盘/index.html`（file://），或 `/api/health` 不通
- **WHEN**: 选中正文
- **THEN**:
  - UI 行为：不出工具条，不出批注栏、不出已读按钮，页面和现在一样能读
  - 恢复路径：从 `http://127.0.0.1:4330/` 打开即可（build.py 和 SKILL 给的就是这个地址）

##### Scenario: 错误 — 服务中途停了
- **GIVEN**: 页面开着时服务被停
- **WHEN**: 点 ⭐ 或改备注
- **THEN**:
  - UI 行为：卡片照常出现，备注右边显示「未保存」和「重试」；划线不丢在页面内存里
  - 恢复路径：服务恢复后点「重试」写入；刷新前没重试的那一条丢弃

##### Scenario: 陈旧 — 原文被重写
- **GIVEN**: 某条划线的原句在经验或知识点重写后已不在页面上
- **WHEN**: 打开这一页
- **THEN**:
  - UI 行为：这条不上色、批注栏不出它的卡片；其余照常
  - 数据：划线不删，推送照常用快照（block、quote）

##### Scenario: 边界 — 选区太短、跨出正文、同一行两条
- **WHEN**: 选中 1 个字；选区一端在左栏目录；同一行先后划两段
- **THEN**: 1 个字不出工具条；跨出正文不出工具条；同一行两条按左右顺序排卡片、各自一条虚线，卡片不重叠

#### Requirement R2：备注编辑与删除

##### Scenario: 正常 — 改备注
- **GIVEN**: 已有一条划线
- **WHEN**: 点卡片改备注，回车
- **THEN**: `划线.json` 里 note 更新；下一次推送用新备注；背景不重写

##### Scenario: 正常 — 删除
- **WHEN**: 悬停卡片点删除图标
- **THEN**: 原文去色、卡片和虚线消失；`划线.json` 删掉这条；之后不再推

##### Scenario: 错误 — 删除时服务不通
- **THEN**: 卡片保留，显示「未保存」和「重试」

##### Scenario: 边界 — 中文输入法选词
- **WHEN**: 输入法候选时按回车
- **THEN**: 不收起输入框（`isComposing` 时忽略回车）

#### Requirement R3：背景与讲解生成

serve.py SHALL 在新建划线后后台生成背景（所有划线）和讲解（仅 ❓），存回这条划线；用户不需要等。

##### Scenario: 正常 — ❓ 一分钟内出讲解
- **GIVEN**: 新建一条 ❓「检查截止点」，备注「和发送时间是一回事吗」
- **WHEN**: 服务调用本机 Claude CLI（非交互，限时 120 秒）
- **THEN**:
  - 数据：gen.status=done，background 两部分：①「项目 › 模块：在做的事」一句（取 doc）②这一处的情况一两句（只依据 block 原文）；explain ≤ 200 字，回答这句话和备注里的疑问
  - UI：页面 SHOULD 在 60 秒内（轮询或刷新时）在这张卡片下面显示讲解

##### Scenario: 错误 — 生成失败或超时
- **THEN**: gen.status=failed、tries+1；页面不出讲解、不出报错；push.py 推之前再触发一次；仍失败时 background 用「doc 一句 + section + block 第一句」拼出来，讲解一段不出

##### Scenario: 降级 — 本机没有 Claude CLI
- **THEN**: 直接按失败处理（拼背景），划线和推送照常

##### Scenario: 边界 — 连续划很多条
- **WHEN**: 一分钟内划 10 条
- **THEN**: 生成排队，一次一个；页面不卡

#### Requirement R4：已读

##### Scenario: 正常 — 点已读，列表变灰
- **GIVEN**: 历史复盘全部未读（`已读.json` 为空）
- **WHEN**: 在一篇复盘最下面点「已读」，回到汇总页
- **THEN**: 按钮变成「✓ 已读」样式；`已读.json` 多这一篇的键；汇总页「最近」和项目页里这一行不透明度 .5，悬停回 1

##### Scenario: 正常 — 取消
- **WHEN**: 再点一次
- **THEN**: 键从 `已读.json` 移除，列表恢复

##### Scenario: 降级 — file:// 打开
- **THEN**: 不出已读按钮；列表不变灰

##### Scenario: 错误 — 服务不通
- **THEN**: 按钮旁显示「未保存」，状态不变

##### Scenario: 边界 — 经验首页
- **THEN**: 经验详情点已读后，经验首页那一行同样变灰

#### Requirement R5：推送

push.py SHALL 按北京时间把划线推到飞书群 Learn With AI，每条共 3 次。

| 次 | 时间 | 推哪些 |
| --- | --- | --- |
| 1 | 每天 21:00「今日新增」 | 今天 21:00（北京时间）以前划的、还没推过的；21:00 以后划的留到第二天 21:00 |
| 2 | 第一次推送后的第二天 09:00「今日复习」 | 已推 1 次、第一次推送是昨天的 |
| 3 | 再过一天 09:00「今日复习」 | 已推 2 次、第一次推送是前天的 |

##### Scenario: 正常 — 晚上推当天新增
- **GIVEN**: 今天 10:00 划了 1 条 ❓、2 条 ⭐，生成都完成
- **WHEN**: 21:00 后的第一次检查
- **THEN**: 群里一张卡片，标题「今日新增 · 3 条」；每条一块浅灰底（`column_set background_style grey-50`，内边距 14px），模块名「背景」「疑问」或「收藏」「备注」加粗、`text_size heading`、正文色，模块之间 14px；背景第一段是「项目 › 模块：在做的事」，第二段是这一处的情况；疑问块：划线原句加粗 + 讲解正文；收藏块：划线原句加粗；备注为空整块不出；不用表情；三条的 pushes 各记 n=1 和消息 id

##### Scenario: 正常 — 早上推复习
- **WHEN**: 次日 09:00 后第一次检查
- **THEN**: 「今日复习 · N 条」，内容和第一次同一份文字（背景、讲解不重写；备注用最新的），pushes 记 n=2；第三天记 n=3，之后不再推

##### Scenario: 空 — 没有要推的
- **THEN**: 不发消息

##### Scenario: 错误 — 飞书发送失败
- **THEN**: 不记 pushes；10 分钟后的下一次检查重发；已发成功的不重复发

##### Scenario: 降级 — 21:00 电脑睡着
- **THEN**: 醒来后当天的第一次检查补推；过了当天，这批并进第二天 21:00 的「今日新增」；复习同理并进下一次 09:00，n 照常递增

##### Scenario: 边界 — 一次很多条
- **WHEN**: 当天划了 25 条
- **THEN**: 按划线时间排，每张卡片最多 10 条，分 3 张发

#### Requirement R6：本地服务与打开方式

##### Scenario: 正常 — 开机即可用
- **GIVEN**: LaunchAgent 已装
- **THEN**: 开机或登录后 `http://127.0.0.1:4330/` 打开工作台；进程退出自动拉起

##### Scenario: 正常 — 复盘写完给 http 地址
- **WHEN**: build.py 编完一篇
- **THEN**: 服务通时打印的浏览器地址是 `http://127.0.0.1:4330/#r=…`；不通时照旧给 file:// 地址

##### Scenario: 错误 — 端口被占
- **THEN**: serve.py 启动失败并在日志里写明端口被占；不换端口

##### Scenario: 边界 — 别人装 skill、没装推送
- **THEN**: 只跑 serve.py 也能划线、看讲解、点已读；推送部分不存在不影响

#### Requirement R7：去掉知识点旧收藏

##### Scenario: 正常
